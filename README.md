## 购买机场前需要知道

### 1. 买机场和买基金一样

当前表现不代表未来表现。机场就是vps+线路，是线路总会遇到各种问题。

### 2. 线路比流量更重要

一般来说专线机场体验最好。专线主要是不过墙，延迟低、网络波动小，日常用起来更顺畅。机场比的是钞能力，速度看总带宽，稳定性看上游线路质量，解锁看落地/解锁商。对我来说，带宽和稳定性最重要。开得久的大机场，遇到域名被墙这类问题，通常也更有处理经验。202604：由于近期国内中转被大规模打击清退，且目前还在持续打击中，因此很多机场无国内中转可用，大部分机场在使用路由好的海外机器做中转，也是直连或者是使用透传专线（避免被通报）。如果是电信网，推荐购买有三网优化或者电信优化的直连机场，否则体验会很差。目前使用第三方客户端基本不存在国内中转了。如果需要专线，可以找只能使用机场自家客户端的，或者建议使用官方客户端的机场。            

### 3. 不要一次买很多年

一次别买太长时间，谁也不知道机场什么时候跑路。TG上过于高调的机场也要谨慎购买。

### 4. 一定准备备用机场

备用很重要，如果经常需要科学上网，就不能只有一个机场，特别是202604大规模清理国内中转机之后很多机场都不稳定，因此高强度翻墙的推荐买多个机场，避免失联。

### 5. 不推荐超便宜机场

不推荐购买太便宜的机场，常见的套路有：1)一开始很便宜或搞超大折扣活动，AFF比例非常高。低价吸引一波来割韭菜，捞一波就跑。别看流量多、单价低就觉得值，不好用也是浪费钱。 2)使用便宜月抛直连线路，成本低。线路变化频繁，随时一键跑路。 3)看着线路多，其实复用的是同一组入口和落地。 很多便宜机场优点只有便宜，稳定性和速度一言难尽。 买多了几家机场就知道：机场便宜不好用，好用不便宜。

### 6.注意省墙差异   
福建，江苏，浙江可能有TLS墙阻断，如果是购买海外直连或者海外中转机场，可能无法使用，这些地区的尽量购买国内中转入口的机场或者是使用白名单的SNI的Vless(Reality)/Anytls直连机场。

## FAQ

### 哪种机场最稳定？

我选机场会先看同一运营商下的晚高峰测速、过去几个月的故障情况，以及出问题后维护是否及时。多入口、有备用线路的机场值得优先考虑，但价格高、节点多也不能保证一直稳定。可以先短期试用，再决定是否长期买。

### 为什么推荐多个机场？

服务器、入口和上游线路都可能出问题，经常需要科学上网的话，建议准备一家备用机场。尽量选线路来源不同的两家，免得共用的上游出故障时一起不能用。

### 为什么很多机场开始用AnyTLS？

一开始是AnyTlS不会被通报，所以很多机场用，然后支持AnyTLS客户端多，且AnyTLS可以直连，目前很多机场没中转/专线用，只能使用直连或海外直连,很多机场就转到AnyTlS。  
      
### 延迟低是不是速度快？

延迟低通常意味着响应快，但下载速度还受带宽、丢包和拥堵影响。低延迟节点也可能带宽不足，测速时要把延迟和下载速度一起看。南方用户可以先试香港节点，再按自己的实际体验选择。

### 为什么机场官网打不开？

可能是域名被屏蔽、DNS解析异常，也可能是官网换了域名或服务器临时故障。先看机场公告、官方客户端或本文保留的备用地址，再换个网络试试。官网打不开和节点不能用，要分开判断。

### 为什么测速快实际体验不好？

先看测试时间和网络：白天测速快，晚高峰可能因用户多而拥堵；移动网络测得好，也不代表电信网络同样好用。客户端、所选节点和访问的网站不同，体验也会有差别。最好用自己的设备，在平时使用的时段试一下。

### 为什么IEPL更贵？

IEPL提供专用传输通道和带宽保障，这类线路的采购、维护成本通常较高。不过机场购买的专线带宽仍会分给多名用户使用，实际体验还要看总带宽、用户数量和上游质量，不能只看“IEPL”这个标签。

### 为什么封订阅推荐使用官方客户端？

部分机场为了减少节点信息外泄，只通过自家客户端提供连接，不再开放通用订阅。如果机场已经限制第三方客户端，小火箭、Clash等就可能无法导入或使用。购买前先确认支持哪些设备，官方客户端是否符合自己的习惯。

## 为什么相信本文？

我从2023年开始持续记录机场测速，每个机场至少观察半年再推荐。各家的历史测速链接都放在介绍里，可以对照过去的记录看线路和速度变化。

跑路或长期超售的机场会移除，临时故障会在对应条目里说明。不会因为AFF保留表现差的机场。
